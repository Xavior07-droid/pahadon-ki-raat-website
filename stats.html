Data controls

Global figures (visits, song plays) are counted with a free, keyless counter service and are shared across every visitor's browser — that part is real, site-wide data. Everything else on this page (referrer, device, viewport, language, mood theme, visit timeline) is recorded only in this browser's local storage, because a fully static site with no backend can't see other people's devices. For real per-visitor analytics (locations, unique visitors, cross-device timelines) you'd want to wire in a proper analytics backend (e.g. Plausible, Umami, or a small serverless function) — happy to help set that up if you want it later.
